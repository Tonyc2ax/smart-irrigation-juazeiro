#  Sistema de Irrigação Inteligente - Vale do São Francisco

Este é um projeto de nível **básico** desenvolvido em Python que simula a lógica de um sistema automatizado de irrigação, pensado para os campos de cultivo de Juazeiro (Bahia, Brasil).

##  Como Funciona
O programa simula a leitura de sensores de umidade do solo e temperatura para tomar decisões automáticas:
* Se a umidade for menor que **40%**, o sistema abre as válvulas de água automaticamente.
* Se a umidade estiver acima desse valor, as válvulas permanecem fechadas para economizar recursos.

##  Tecnologias Utilizadas
* **Python 3** (Lógica de programação e estruturas condicionais).
